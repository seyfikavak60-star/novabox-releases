# NovaBox official APK distribution

This repository is for official external NovaBox APK releases only.

- No application source code, signing keys, passwords, customer information or debug/test APKs are published here.
- Official signed external APK files belong in GitHub Releases, not the source tree.
- Android App Bundles for Google Play are distributed through Google Play, not this repository.
- `member/latest.json` is intentionally `available: false` until a verified official external APK has been published and its download has been independently checked.
- Updates must match the installed application package and signing certificate. Users approve installation through their device's system installer.

The feed must not advertise a version before its exact release asset, size, SHA-256, package, minimum Android version and supported ABIs have been verified. Do not replace or delete an already-published official release as part of an ordinary update.
